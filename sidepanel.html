Durable storage

Browser-only is the default. Turn on a local mirror once and FileChute remembers that folder and writes there automatically. Turn it off again to return to browser-only storage. There is no per-item Save step.

If Chromium ever drops filesystem permission, FileChute keeps the remembered folder handle and asks only to reconnect that same folder rather than making you choose it again.
